User guide

ClassAct

A studio for NVIDIA Object-Oriented Agents. An agent is a Python class. Methods are capabilities. A method whose body is … is filled in at runtime by an LLM.

Default model: open Nemotron 3.5 Lightning on hosted NIM. No GPU on your desk.

Architecture

Browser
   │  HTTP + SSE
   ▼
ClassAct  FastAPI
   ├─ Inspect   catalog/ + workspace/
   ├─ Run       await a typed method
   ├─ Watch     OpenTelemetry span tree
   ├─ Build     class graph → Python file
   ├─ NOOA      class = agent, … = LLM
   └─ LiteLLM ── HTTPS ──► NIM  Lightning

ClassAct does not fork NOOA. It reflects classes, runs them with your NIM key, and writes new modules into workspace/.

Quick start

cp .env.example .env   # NVIDIA_API_KEY from build.nvidia.com
./run.sh
# → http://127.0.0.1:7877

Inspect and Build work without a key. Run and Watch need NIM.

NOOA_MODEL=nvidia_nim/nvidia/nemotron-3.5-lightning-30b-a3b
NIM_MODEL_ID=nvidia/nemotron-3.5-lightning-30b-a3b

Never commit .env.

Inspect

The rail lists agents from catalog/ (shipped) and workspace/ (generated). The card is a UML view of the class:

  • Fields — public annotated state
  • Methods — … is agentic (LLM); def is ordinary Python
  • Source — the file on disk

Click a method row to jump to Run. Open in Build loads the class onto the canvas.

Run

Run is a prompt console.

  1. Pick agent, method, and model. Agentic methods are selected by default.
  2. Type into the large message box. That is the method’s main text argument (text, message, prompt, …).
  3. Fill extra arguments (for example order_id) under the prompt.
  4. Use a Try chip, or press ⌘↵ / Ctrl+Enter.

The Reply stays on this tab. Structured objects render as cards; JSON sits underneath. Spans stream in Live trace — submitting does not navigate to Watch.

AgentMethodWhat to type
ClassifierAgent classify A customer review. Returns a typed FeedbackAnalysis.
SupportAgent triage A support message plus order_id (ORD-1001, ORD-2044, ORD-3302).

Watch

Each box is an OpenTelemetry span. Nesting follows the Python call tree, not only the LLM transcript:

  • method.<name> — agent method
  • generation — Predict or CodeAct loop
  • litellm.acompletion — NIM call
  • code_execution — a CodeAct Python cell

Build

A live object graph.

  • The class is the center node. Click to edit name, role, and fields.
  • Methods orbit it. Click to inspect; drag to rearrange. + adds a capability.
  • Kind: Agentic (…) vs Python tool.
  • Strategy: Predict (typed, no code exec) vs CodeAct (model writes Python).
  • Live Python updates as you type. Generate class writes workspace/.

Templates: Headline, Classifier, Support, Blank. Class names must be PascalCase.

Safety

NOOA can execute model-generated Python. New Build agents default to Predict. Shipped CodeAct tools are in-memory only. Framework checks are not a sandbox — use a container, a VM, or NVIDIA OpenShell.
